# Unit economics

The reference model deliberately separates implementation cost, recurring cloud consumption, recurring operations, avoided cost and revenue uplift.

```text
monthly net value = avoided cost + revenue uplift - cloud cost - operations cost
payback months = implementation cost / monthly net value
year-one ROI = (year-one benefits - year-one costs) / year-one costs
```

Before a commercial proposal, every input needs a named owner, source, timestamp, currency, tax treatment, confidence range and sensitivity case. Provider calculators are estimates; invoices and measured utilization are stronger evidence.

Recommended scenarios:

- downside: no revenue uplift, migration delay and 20% higher consumption;
- base: approved workload and utilization assumptions;
- upside: verified automation adoption and capacity commitments.

Do not combine avoided cost and revenue uplift if they describe the same value. Do not present labor capacity released as cash savings unless headcount or external expenditure actually changes.
