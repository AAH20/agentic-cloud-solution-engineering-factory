# Product and distribution roadmap

## v0.1 — executable proof

- deterministic qualification, option ranking and economics;
- traceability, proposal, SOW and evidence receipt;
- synthetic VMware-to-Azure/AKS engagement.

## v0.2 — engineering validation

- JSON Schema validation and versioned migrations;
- Terraform/Bicep plan ingestion;
- Checkov, Infracost and Azure Resource Graph adapters;
- C4 and network-diagram renderer;
- scenario and sensitivity analysis.

## v0.3 — agentic orchestration

- durable LangGraph/Temporal workflow;
- MCP/A2A adapters and model evaluation;
- retrieval with document-level citations;
- Kubernetes Agent Sandbox execution;
- exact artifact-bound approval.

## v1.0 — commercial control plane

- multi-tenant isolation and SSO;
- CRM, ticketing, billing and document integrations;
- signed evidence custody and approval ledger;
- actual-versus-estimated cost calibration;
- private deployment and managed-service operations.

Distribution begins with a useful CLI and GitHub Action. The highest-leverage upstream targets are Backstage templates, cloud architecture communities, Terraform/OpenTofu ecosystems, Kubernetes SIG Apps and MSP solution-engineering teams.
